# Portfolio Website

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Features
- Sticky navbar with active section highlighting
- Hero section with typing effect
- About, Education, Skills and Projects sections
- Contact cards and a contact form with validation
- Scroll reveal animations and back-to-top button
- Fully responsive for mobile, tablet and desktop

## Projects Shown
- Student Management System (Java, JDBC, PostgreSQL, Maven)
- Portfolio Website (HTML, CSS, JavaScript)
- Login Page (HTML, CSS, JavaScript)

## Tech Stack
HTML5, CSS3, JavaScript (ES6)
